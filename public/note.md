# 📁 `public/` – Statiska Webbresurser

## 🎯 Syfte
Denna mapp exponeras offentligt av Express via `express.static(...)`. Här ligger alla filer som klientens webbläsare hämtar direkt utan serverbearbetning.

## 📦 Vad ska finnas här?
- **`images/`**: Bilder på hästar, profilfoton på personal/elever, ikoner och logotyper.
- **`javascripts/`**: Klient-side JavaScript för interaktivitet (t.ex. drag-and-drop, modaler, filter).
- **`stylesheets/`**: CSS-stilark, Tailwind-komponenter och anpassade stilar.
